# Benutzeroberfläche

## Übersicht

Die PMTool-GUI basiert auf PySide6 (Qt for Python) und bietet eine dreispaltige Ansicht.

## Komponenten

### 1. Projektliste (Links)

**Widget:** `ProjectListWidget`

Funktionen:
- Liste aller Projekte (alphabetisch sortiert)
- Buttons: Neu, Bearbeiten, Löschen, CSV Export
- Auswahl löst Laden der Tasks aus

### 2. Task-Tabelle (Oben rechts)

**Widget:** `TaskTableWidget`

Spalten:
| Spalte | Beschreibung |
|--------|--------------|
| Titel | Task-Name (Überfällige rot markiert) |
| Owner | Verantwortliche Person |
| Start | Startdatum (DD.MM.YYYY) |
| Ende | Enddatum |
| Status | Farbcodiert (Grau/Blau/Grün) |
| Priorität | Farbcodiert (Grau bis Rot) |
| Fortschritt | Prozentanzeige |

Funktionen:
- Sortierung nach Priorität (absteigend) und Startdatum
- Doppelklick öffnet Bearbeiten-Dialog
- Buttons: Task hinzufügen, Bearbeiten, Löschen

### 3. Gantt-Widget (Unten rechts)

**Widget:** `GanttWidget`

Features:
- Horizontale Zeitbalken je Task
- Farbcodierung nach Status
- Fortschrittsanzeige im Balken
- Wochenenden grau hinterlegt
- Heute-Linie (gestrichelt, rot)
- Automatische Skalierung

## Dialoge

### Projekt-Dialog

**Widget:** `ProjectDialog`

Felder:
- Name (Pflichtfeld)
- Beschreibung (mehrzeilig)
- Startdatum (Kalender-Popup)
- Enddatum (Kalender-Popup)

### Task-Dialog

**Widget:** `TaskDialog`

Felder:
- Titel (Pflichtfeld)
- Owner
- Start-/Enddatum
- Status (Dropdown)
- Priorität (Dropdown)
- Fortschritt (Spinner 0-100)
- Notizen (mehrzeilig)

## Farbschema

### Status-Farben
| Status | Farbe | Hex |
|--------|-------|-----|
| TODO | Grau | #6c757d |
| IN_PROGRESS | Blau | #0d6efd |
| DONE | Grün | #198754 |

### Priorität-Farben
| Priorität | Farbe | Hex |
|-----------|-------|-----|
| LOW | Grau | #6c757d |
| MEDIUM | Blau | #0d6efd |
| HIGH | Orange | #fd7e14 |
| CRITICAL | Rot | #dc3545 |

## Tastenkürzel

| Aktion | Kürzel |
|--------|--------|
| Neues Projekt | - |
| Neuer Task | - |
| Bearbeiten | Doppelklick |

## Responsivität

Das Hauptfenster verwendet `QSplitter` für anpassbare Bereichsgrößen:
- Projektliste: 250px initial
- Task-Bereich: Flexibel
- Gantt/Tabelle: Vertikaler Splitter
